# Pressure Cooker: A Chef’s Nightmare

## How to Start
Run the main.py file. The selection screen will appear. Click on a card to start the game.

## Controls

-  Arrow keys : Move the chef
-  Spacebar: Activate spatula (temporary immunity, limited uses)

## Gameplay
Move around the map to collect ingredients and earn points before time runs out. Avoid goblins, as they remove collected items when they touch you.

## Objective
Reach the target score and continue to the next level.
